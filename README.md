# Выжать максимум из подписки с несколькими моделями

Скилл для ИИ-ассистента: превращает подписку «много моделей за фиксированные деньги» в рабочий
оркестратор, где каждая задача уходит на модель, которая реально сильнее в этом домене, а не на ту,
что стоит по умолчанию.

Подходит для любой подписки, дающей несколько моделей: OpenCode Go / Zen, OpenRouter, Groq, Together,
Cerebras, корпоративные OpenAI-совместимые шлюзы, локальные стеки с несколькими моделями.

## Зачем

Подписка с 20–30 моделями обычно используется на 5–10 %: агент сидит на одной модели, потому что
её выбрали один раз в конфиге. При этом у моделей в тарифе разные сильные стороны (агентский терминал,
патчи в репозитории, знания, документы, длинный контекст, безопасность), разные цены за задачу и
разные лимиты. Один и тот же бюджет даёт заметно больше, если развести задачи по моделям.

## Что делает агент по этой инструкции

1. **Инвентаризация** – какие модели реально доступны из твоей сети, с какими лимитами, контекстом и модальностями.
2. **Проверка живости** – минимальный запрос на каждую модель: 200, гео-блок, «coming soon», требуется тумблер приватности.
3. **Доказательства** – что каждая модель умеет по независимым прогонам, а не по пресс-релизу.
4. **Маршруты** – таблица «домен задачи → основная модель, резерв, запрещённые».
5. **Внедрение** – настройка оркестрации в твоём агенте (для Hermes есть готовый плагин и конфиг).
6. **Калибровка** – прогон 8 своих реальных задач по 4 маршрутам, слепая оценка, правка маршрутов.

## Быстрый старт

Отдай своему агенту ссылку на этот репозиторий и промпт из [`AGENT_PROMPT.md`](AGENT_PROMPT.md).
Дальше он читает [`SKILL.md`](SKILL.md) и идёт по шагам сам.

```
https://github.com/Arturio48/model-routing-skill
```

Ориентир по времени и расходу: 20–40 минут работы агента, плюс несколько десятков коротких
запросов на зондирование моделей. Калибровка – отдельный заход на 30–60 минут.

## Ключевые находки, на которых всё построено

- Вендорские агентские числа на бенчмарках старого поколения завышены систематически: на 24
  сопоставимых парах медиана −5 п.п., худший случай −33 п.п. На новом поколении (Terminal-Bench 4.0)
  расхождение почти нулевое, а знания и мультимодальность вендоры заявляют честно.
- Цена за решённую задачу информативнее цены за миллион токенов: в одном тарифе разница между
  моделями на одной задаче достигала 150 раз при разнице в качестве 20 п.п.
- Лимит важнее прайса: 5-часовое окно в 20 % месячного лимита означает, что у «дешёвой по доллару
  за миллион» модели тяжёлых прогонов помещается меньше десяти.
